Agrios — Фермерське господарство
Вебсайт для фермерського господарства, розроблений як навчальний проєкт під час проходження виробничої практики. Ресурс створений для презентації органічної продукції, опису переваг фермерства та надання інформації про послуги компанії.

Технології
Проєкт реалізовано з використанням сучасних інструментів фронтенд-розробки:

HTML5 — семантична розмітка сторінок.

CSS3 — стилізація, адаптивна верстка (Flexbox, Grid, медіазапити).

JavaScript (ES6+) — реалізація інтерактивних елементів інтерфейсу.

Основні можливості
Адаптивний дизайн: Коректне відображення на пристроях з різною роздільною здатністю (від мобільних телефонів до десктопів).

Інтерактивна навігація: Мобільне меню типу бургер з анімацією трансформації іконки.

Сучасний інтерфейс: Використання SVG-графіки, кастомних анімацій при наведенні та продуманих відступів.

UX-елементи: Реалізація складних візуальних блоків (накладання зображень, декоративні псевдоелементи).

Структура проєкту
Проєкт складається з наступних ключових секцій:

Header: Адаптивна панель навігації.

Hero: Головний банер із декоративним оформленням.

Features: Блок з ключовими перевагами господарства.

About: Секція про компанію з інтегрованими медіа-елементами.

Services: Сітка послуг з інтерактивними картками.
